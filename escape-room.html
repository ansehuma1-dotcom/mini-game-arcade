Escape Room

You are locked in a room! Search the painting, the bookshelf and the drawer to find 3 hidden number clues, then crack the 3-digit code to unlock the door and escape.

Clues found: 0/3 Code attempts: 0

You are locked in! Tap the painting, bookshelf, drawer and door to search the room.

– – –

How to play: tap the painting, bookshelf and drawer to find the 3 number clues — count the candles, the books and the keys. The drawer also hides the brass key you need before the door can be tried. Then tap the digit buttons (or use your keyboard digits 0–9) and press Try Code — or Enter — to test the 3-digit code.
