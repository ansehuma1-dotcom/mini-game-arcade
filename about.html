About Mini Game Arcade

Mini Game Arcade is a small, free website for quick browser games. It is run as an independent hobby project. The first game is Fruit Slice, a fruit-slicing game with original, simple graphics.

We only list games that are finished and playable. New games are added one at a time, after testing on phone and desktop.
